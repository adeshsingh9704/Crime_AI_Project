# Crime AI

Crime AI is an academic demonstration project that combines:

- Crime hotspot detection
- Browser GPS location
- Interactive crime map
- Crime-category prediction
- Legal case text similarity
- Image similarity demonstration
- Crime statistics
- PDF report generation
